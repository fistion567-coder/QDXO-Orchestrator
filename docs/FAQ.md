# ❓ FAQ QDXO

## 🇪🇸 Español

### ¿Qué es QDXO?
QDXO es un orquestador que convierte tu dispositivo en un nodo activo de la red, 
aportando validación y seguridad mientras recibes recompensas en tokens QDXO.

### ¿Cómo instalo el software?
Descarga el repositorio desde GitHub y sigue las instrucciones en el README. 
Cada instalación fortalece el ecosistema.

### ¿Qué gano al participar?
Recibes tokens QDXO como recompensa por validar y aportar recursos a la red.

### ¿Es seguro?
Sí. El orquestador no accede a tus datos personales, solo utiliza recursos básicos 
de tu dispositivo para participar en la red.

### ¿Cómo funciona el orquestador?
El orquestador distribuye tareas entre nodos, valida resultados y envía recompensas 
a través de smart contracts en Solana.

## 🇬🇧 English

### What is QDXO?
QDXO is an orchestrator that turns your device into an active network node, 
providing validation and security while earning QDXO tokens.

### How do I install the software?
Download the repository from GitHub and follow the instructions in the README. 
Each installation strengthens the ecosystem.

### What do I earn by participating?
You receive QDXO tokens as rewards for validating and contributing resources to the network.

### Is it safe?
Yes. The orchestrator does not access your personal data, it only uses basic 
resources from your device to participate in the network.

### How does the orchestrator work?
The orchestrator distributes tasks among nodes, validates results, and sends rewards 
through smart contracts on Solana.
