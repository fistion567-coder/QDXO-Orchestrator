# Contributing to QDXO

---

## 🇪🇸 Guía para Colaboradores
Gracias por tu interés en contribuir a QDXO. Este proyecto busca construir un ecosistema blockchain inclusivo y accesible.  

### Pasos para contribuir
1. Haz un fork del repositorio.  
2. Crea una rama para tu aporte (`feature/nueva-funcionalidad`).  
3. Realiza tus cambios y asegúrate de que el código esté documentado.  
4. Envía un Pull Request describiendo claramente tu aporte.  

### Buenas prácticas
- Usa un estilo de código consistente.  
- Documenta tus funciones y módulos.  
- Respeta la filosofía del proyecto: accesibilidad, descentralización y transparencia.  

---

## 🇬🇧 Contributor Guide
Thank you for your interest in contributing to QDXO. This project aims to build an inclusive and accessible blockchain ecosystem.  

### Steps to contribute
1. Fork the repository.  
2. Create a branch for your contribution (`feature/new-functionality`).  
3. Make your changes and ensure the code is documented.  
4. Submit a Pull Request clearly describing your contribution.  

### Best practices
- Use consistent coding style.  
- Document your functions and modules.  
- Respect the project philosophy: accessibility, decentralization, and transparency.
